이상탐지(anomaly detection)는 정상적인 패턴에서 벗어난 데이터를 찾아내는 작업이다. 제조 공정의 불량품 검출, 금융 거래의 사기 탐지, 서버 지표의 장애 예측처럼 현업에서 마주치는 문제 상당수가 이상탐지 문제로 환원된다. 이 글은 이상탐지를 처음부터 체계적으로 공부하고, 학습한 내용을 실제 시스템에 적용할 수 있는 수준까지 정리하는 시리즈의 목차다. 통계 기반 이상탐지 기법을 현업에 적용하려는 개발자와 데이터 엔지니어를 대상으로 하며, 시리즈를 끝까지 읽으면 정형 데이터와 시계열 데이터 각각에 어떤 기법이 적합한지 판단하고 실제 파이프라인에 적용할 감각을 얻을 수 있다.

## 두 자료를 뼈대로 삼는 이유

공부의 뼈대로 두 자료를 사용한다. 하나는 이상탐지 실천 지식을 다루는 일본 서적으로, 통계적 가설검정과 확률분포 최우추정을 기반으로 한 고전적 이상탐지 기법을 1변수 데이터부터 다변수 데이터, 회귀 모델, 베이지안 모델링까지 단계적으로 설명한다. 다른 하나는 시계열 이상탐지 방법론 10년을 정리한 서베이 논문으로, 거리 기반, 밀도 기반, 예측 기반이라는 프로세스 중심 분류체계로 최근 알고리즘까지 아우른다.

두 자료는 다루는 데이터 형태(정형 데이터와 시계열)와 접근 방식(통계적 검정과 알고리즘 분류)이 다르다. 그런데도 나란히 놓고 읽을 수 있는 이유는 "정상 상태를 어떻게 모델링하고 그로부터의 이탈을 어떻게 측정하는가"라는 같은 질문에 각자의 방식으로 답하기 때문이다. 실제로 두 자료를 겹쳐보면 대응 관계가 드러난다.

| 책이 다루는 기법 | 논문의 분류체계에서의 위치 |
|---|---|
| 홀텔링 이론, 마할라노비스-다구치법 | 밀도 기반, 분포 기반 |
| 혼합정규분포(GMM), 비모수적 kNN | 밀도 기반, 인코딩 기반 / 거리 기반, 근접 기반 |
| SVM 기반 이상탐지(지도학습) | 밀도 기반, 분포 기반(One-Class SVM 계열) |
| 선형회귀, 리지회귀, 베이지안 회귀 | 예측 기반, 예측 오차 기반 |

책은 정형 데이터에서 각 통계 모델이 어떻게 이상 점수를 계산하는지 수식 수준까지 파고들고, 논문은 그 계산 방식이 시계열이라는 더 넓은 문제에서 어떤 계열로 묶이는지 지도를 그려준다. 이 시리즈는 책의 순서를 따라 개별 기법을 익힌 뒤, 각 편의 끝에서 논문의 분류체계 위에 그 기법을 위치시키는 방식으로 진행한다. 예제 코드는 책에 딸린 공개 저장소를 재구성해 각 편에 GitHub 링크로 붙인다.

## 1편. 이상탐지 기초와 통계적 기초 접근

**주요 내용**
- 이상탐지란 무엇인가, 이상탐지의 과제와 해결책 (1.1, 1.2)
- 이상탐지 실시 흐름 (1.3)
- 각 수법의 구분 사용 기준 (1.6)
- 실시스템에서 빠지기 쉬운 함정 (1.7)
- 탐색적 데이터 분석(EDA)과 데이터 시각화, 샘플 데이터 생성 (2장)
- 지도학습 기반 접근: SVM (3.3), 로지스틱 회귀 (3.4) — SVM은 논문의 밀도 기반, 분포 기반(One-Class SVM 계열)에 해당
- 지도학습 기반 이상탐지의 문제점 (3.5)

**목적**: 이상탐지의 전체 그림을 잡고, 접근 방향을 결정하는 기준 세우기  
**타겟**: 초보자 ~ 입문자

**상세 목차**

1. 이상탐지란 무엇인가 (1.1)
   - 정상 상태와 이상 상태를 가르는 기준, 이상탐지가 실무에서 등장하는 대표적인 장면
2. 이상탐지에서 부딪히는 과제와 해결 방향 (1.2)
   - 라벨 부족, 클래스 불균형 등 이상탐지 특유의 제약과 그에 대응하는 접근법의 갈래
3. 이상탐지를 실제로 수행하는 흐름 (1.3)
   - 데이터 확보부터 모델링, 평가, 운영까지 이어지는 절차
4. 어떤 수법을 고를 것인가 (1.6)
   - 지도학습과 비지도학습 중 데이터 상황에 따라 고르는 기준
5. 실 시스템에서 흔히 빠지는 함정 (1.7)
   - 이상탐지를 실제 서비스에 붙일 때 반복되는 실수
6. 데이터를 먼저 들여다보기, 탐색적 데이터 분석과 시각화 (2장)
   - 구조화 데이터 읽기, EDA, 시각화, 샘플 데이터 생성 / 예제: `series01/eda.py`
7. 지도학습으로 이상탐지에 접근하기, SVM (3.3)
   - 예제: `series01/supervised.py`
8. 지도학습으로 이상탐지에 접근하기, 로지스틱 회귀 (3.4)
   - 예제: `series01/supervised.py`
9. 지도학습 기반 이상탐지가 갖는 한계 (3.5)
   - 이 한계가 다음 편에서 비지도학습으로 넘어가는 이유가 된다
10. SVM이 논문의 분류체계에서 차지하는 위치
    - 밀도 기반, 분포 기반(One-Class SVM 계열)과의 대응 관계, 4편에서 다시 다룰 지점 예고

## 2편. 비지도 학습 기반 이상탐지: 단변량에서 다변량까지

**주요 내용**
- 확률분포와 최우추정 (4.3) — 이후 기법들의 공통 기반
- 홀텔링 이론에 의한 이상탐지: 1변량 (4.4, 4.5), 다변량 (6.3) — 논문의 밀도 기반, 분포 기반에 해당
- 1차원 비정규분포의 최우추정에 의한 이상탐지 (4.6)
- 계수 데이터 처리: 이항분포 (5.3), 포아송분포 (5.4), 과분산 대처 - 베타이항/음이항분포 (부록)
- 다변량 고전 기법:
  - 마할라노비스-다구치법 (6.4) — 논문의 밀도 기반, 분포 기반에 해당
  - 혼합정규분포모델(GMM) (6.5) — 논문의 밀도 기반, 인코딩 기반에 해당
  - 비모수적 방법, kNN (6.6) — 논문의 거리 기반, 근접 기반에 해당

**실습 강조**: GitHub 예제 notebooks 활용한 비교 실험  
**목적**: 라벨이 부족한 현실에서 강력한 비지도 기법 익히기

**상세 목차**

1. 확률분포와 최우추정 다시 보기 (4.3)
   - 비지도 이상탐지가 확률분포 위에서 이상 점수를 계산하는 방식의 기초 / 예제: `series02/univariate.py`
2. 홀텔링 이론으로 1변량 데이터의 이상을 탐지하기 (4.4, 4.5)
   - 샘플 크기가 클 때와 작을 때 적용이 어떻게 달라지는지 / 예제: `series02/univariate.py`
3. 정규분포를 벗어난 데이터 다루기 (4.6)
   - 1차원 비정규분포의 최우추정으로 이상을 탐지하는 방법 / 예제: `series02/univariate.py`
4. 계수 데이터의 이상을 탐지하기, 이항분포와 포아송분포 (5.3, 5.4)
   - 연속형이 아닌 계수형 데이터에 최우추정을 적용하는 방법 / 예제: `series02/count_data.py`
5. 분산이 예상보다 큰 계수 데이터 다루기, 과분산 대처 (부록)
   - 베타이항분포, 음이항분포로 과분산을 반영하는 방법 / 예제: `series02/count_data.py`
6. 홀텔링 이론을 다변량으로 확장하기 (6.3)
   - 예제: `series02/multivariate.py`
7. 다변량 데이터에 마할라노비스-다구치법 적용하기 (6.4)
   - 예제: `series02/multivariate.py`
8. 혼합정규분포모델(GMM)로 여러 정상 군집을 반영하기 (6.5)
   - 예제: `series02/nonparametric.py`
9. 분포를 가정하지 않고 이상을 탐지하기, 비모수적 kNN (6.6)
   - 예제: `series02/nonparametric.py`
10. 2편에서 다룬 기법들이 논문의 분류체계에서 차지하는 위치
    - 홀텔링 이론·마할라노비스-다구치법은 밀도 기반, 분포 기반 / GMM은 밀도 기반, 인코딩 기반 / kNN은 거리 기반, 근접 기반

   - 예제: `series03/regression.py`
4. 변수가 많을 때 안정적으로 추정하기, 리지회귀 (7.5)
   - 예제: `series03/regression.py`
5. 정규분포를 벗어난 출력 다루기, 비정규 GLM과 감마회귀 (7.6)
   - 예제: `series03/regression.py`
6. 베이지안 추정과 베이지안 통계 모델링 기초 (8.2)
   - 예제: `series03/bayesian.py`
7. MCMC로 사후분포를 추정하기 (8.3)
   - 예제: `series03/bayesian.py`
8. 베이지안 선형회귀로 이상을 탐지하기 (8.4)
   - 예제: `series03/bayesian.py`
9. 베이지안 이항 로지스틱 회귀와 포아송 회귀 (8.5, 8.6)
   - 예제: `series03/bayesian.py`
10. GLMM과 계층 모델로 개체 간 차이를 반영하기, 랜덤효과 (8.7, 8.8)
    - 예제: `series03/bayesian.py` (판매자 그룹별 잔차로 그룹차를 예시)
11. 3편에서 다룬 기법들이 논문의 분류체계에서 차지하는 위치
    - 선형회귀·리지회귀·베이지안 회귀 계열은 예측 기반, 예측 오차 기반

## 4편. 시계열 이상탐지의 프로세스 중심 분류체계

**주요 내용**
- 시계열 이상의 세 가지 유형: 점 이상, 맥락적 이상, 집단적 이상 (2.2)
- 프로세스 중심 분류체계의 전체 그림(거리 기반 / 밀도 기반 / 예측 기반)과, 1~3편에서 이미 다룬 기법이 그 안에서 차지하는 위치 재확인
- 거리 기반 중 1~3편에서 다루지 않은 기법: 불일치 기반(Matrix Profile, STAMP, STOMP, SCRIMP 등), 클러스터링 기반(NormA, SAND 등) (6장)
- 밀도 기반 중 1~3편에서 다루지 않은 기법: 그래프 기반(Series2Graph, DADS 등), 트리 기반(Isolation Forest 계열), 인코딩 기반 중 PCA·HMM·베이지안 네트워크·문법 기반 기법 (7장) — PCA는 논문에만 등장, 책/저장소에는 없음
- 예측 기반 중 시계열 특화 기법: 지수평활, ARIMA, LSTM, GRU, Echo State Network, HTM (예측 오차 기반), Autoencoder, GAN (재구성 오차 기반) (8장)

**실습**: 기본 시계열 baseline 구현  
**목적**: 현대 시계열 이상탐지의 큰 그림 이해

**상세 목차**

1. 시계열 데이터에서 이상은 무엇을 뜻하는가, 점 이상·맥락적 이상·집단적 이상 (2.2)
2. 프로세스 중심 분류체계란 무엇인가, 거리 기반·밀도 기반·예측 기반 세 갈래 (3장, 6~8장 개요)
3. 1~3편에서 다룬 기법이 이 분류체계 어디에 속하는지 정리
