[Mole](https://mole.fit/ko/)은 macOS의 디스크 사용량을 분석해 불필요한 파일을 삭제하고 시스템을 관리할 수 있는 유틸리티이다. 무료 CLI 버전만으로도 CleanMyMac, AppCleaner, DaisyDisk, iStat Menus 같은 프로그램이 처리하는 기능의 상당 부분을 대체할 수 있다.

**무료 CLI와 유료 GUI**

Mole에는 터미널에서 사용하는 무료 CLI 버전과 유료 GUI 버전이 있다. 여기에서는 무료 CLI 버전을 기준으로 소개한다. CLI 버전은 [오픈 소스](https://github.com/tw93/Mole)로 공개되어 있고, 기능 제한을 풀기 위해 돈을 낼 필요도 없고 구독료도 없다.

**기존 제품들과 비교**

**Mole CLI 버전에서 할 수 있는 것들**

- 시스템 캐시 및 로그 정리
- 앱과 잔여 파일(LaunchAgent, 환경설정 등) 제거
- 디스크 사용량 분석
- CPU·메모리·디스크·네트워크 상태 확인
- 프로젝트 빌드 산출물 제거
- macOS 유지 관리와 Mole 자체 업데이트

**Mole 설치 방법**

```bash
$ brew install mole

# 혹은

$ curl -fsSL https://raw.githubusercontent.com/tw93/mole/main/install.sh | bash
```

**삭제 명령어를 쓰기 전에 알아둘 것**

잘못 삭제해서 Mac을 쓰는 데 문제가 생길까 걱정된다면 무엇을 삭제하는지 확인하는 습관을 들이는 것이 좋다. Mole에는 실제로 파일을 삭제하지 않고 어떤 작업을 할지 미리 보여주는 `--dry-run` 옵션이 있고, 파일을 지우는 명령어(`clean`, `uninstall`, `purge`)는 모두 이 옵션을 지원한다. 삭제 방식도 명령어마다 다르다. `mo uninstall`과 `mo analyze`는 확인 후 휴지통으로 보내지만, `mo clean`과 `mo purge`는 영구 삭제한다.

**Mole 명령어들**

**1. 불필요한 파일 삭제**

먼저 무엇을 지우는지 확인한다.

```bash
$ mo clean --dry-run
```

문제가 없다면 실제 정리 작업을 실행한다.

```bash
$ mo clean
```

특정 캐시가 삭제되지 않도록 보호하려면 다음 명령으로 화이트리스트를 관리한다. `mo clean`은 기본으로 휴지통(`~/.Trash`)까지 비우므로, 휴지통을 유지하고 싶다면 이 메뉴에서 Trash를 선택해 둔다.

```bash
$ mo clean --whitelist
```

**2. 앱 제거**

앱을 관련 LaunchAgent, 환경설정, 잔여 파일과 함께 제거한다. 설정이나 플러그인 같은 개인 데이터는 기본으로 남겨 두고, 이미 지운 앱의 잔여 파일은 `mo clean`이 찾아낸다.

```bash
$ mo uninstall --dry-run
$ mo uninstall
```

**3. 디스크 사용량 분석**

디스크 전체의 사용량을 알아야 한다면 인자 없이 실행한다.

```bash
$ mo analyze
```

특정 폴더만 확인해 보려면 경로를 넘긴다.

```bash
$ mo analyze ~/Documents
```

외장 디스크는 기본 분석에서 제외되므로 따로 지정한다.

```bash
$ mo analyze /Volumes
```

**4. macOS 유지 관리**

각종 시스템 캐시와 데이터베이스, macOS 서비스를 정리하거나 다시 만드는 유지 관리 작업을 수행한다. 이것도 `--dry-run`으로 작업 내용을 먼저 확인한다.

```bash
$ mo optimize --dry-run
```

macOS를 실제 최적화하려면 옵션 없이 실행한다.

```bash
$ mo optimize
```

**5. 프로젝트 빌드 산출물 제거**

프로젝트가 쌓이다 보면 `node_modules`, `target`, `build`, `dist`처럼 다시 만들 수 있는 산출물이 수십 GB가 되기 때문에 정리하는 게 좋다. 최근 7일 안에 변경된 산출물은 기본으로 선택에서 빠진다.

```bash
$ mo purge --dry-run
```

실제 정리를 한다면 옵션 없이 실행한다.

```bash
$ mo purge
```

**6. Mac 상태 확인**

CPU와 메모리, 디스크, 네트워크, 배터리, 실행 중인 프로세스 등의 상태가 터미널에 실시간으로 표시된다.

```bash
$ mo status
```

**7. Mole 업데이트**

Mole 자체는 다음 명령으로 최신 버전으로 올린다.

```bash
$ mo update
```
